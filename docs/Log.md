### Jitter Calculation

Implemented jitter calculation using RTT variation between consecutive probes.

```go
diff := rtts[i] - rtts[i-1]

if diff < 0 {
    diff = -diff
}

totalDiff += diff
```

Average jitter is calculated as:

```go
jitter = totalDiff / time.Duration(len(rtts)-1)
```
